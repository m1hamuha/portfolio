# site: профиль в Google Картах и простой сайт

Цена на сайте: €29 разово. У shop, fitness, clinic, cleaning, other отмечены сторонние расходы (домен).
Проверено 27.11.2026. Что не удалось проверить первоисточником, помечено «не проверено».

Состав набора:

- `build.mjs` + `lib/` - генератор одностраничного сайта из `business.json`: страница на каждом языке (de, en, ru, uk), цены, фото, часы с бейджем «сейчас открыто», районы работы, кнопки «Позвонить», «WhatsApp», «Маршрут», форма записи на пробное, Impressum и Datenschutz (шаблоны), JSON-LD для Google, robots.txt, sitemap.xml. Без внешних шрифтов, скриптов, карт и cookies, поэтому без баннера согласия. Строгий CSP (скрипт по хешу).
- `apps-script/Site.gs` - бэкенд в Google-аккаунте клиента: цены из Google Таблицы (клиент правит в приложении Таблиц, сайт показывает) и приём заявок с формы (строка в таблицу + письмо владельцу, удаление через 90 дней).
- `gbp/checklist.mjs` - лист заполнения Google Business Profile из того же `business.json`: что в какое поле, часы, описание, услуги с ценами, WhatsApp-ссылка, фото. Плюс проверка того, за что Google режет профиль (ключевые слова в названии, ссылки и телефоны в описании, больше 750 знаков).
- `examples/` - вымышленные: salon (de, ru, uk), shop (цены из таблицы), fitness (запись на пробное), clinic (Impressum для врачей), trades (без адреса, районы), фото-заглушки.
- `test/` - офлайн-тесты: `node --test ops/kit/site/test/*.test.mjs` (14 тестов, все проходят, сеть не используется). Плюс вручную: страницы открыты в headless Chrome, скрипт работает под CSP, бейдж «открыто» заполняется.

## 2. Стек

- Хостинг: Cloudflare Pages на бесплатном тарифе. По документации Cloudflare: статика бесплатна и без лимита запросов, 500 сборок в месяц, 100 своих доменов на проект, 20 000 файлов, 100 проектов на аккаунт ([limits](https://developers.cloudflare.com/pages/platform/limits/)). Условия коммерческого использования бесплатного тарифа отдельно не проверял (не проверено). Альтернатива: GitHub Pages (`"hosting": "github"` меняет текст в Datenschutz), но у GitHub ограничения на сайты, которые служат в основном коммерции, поэтому по умолчанию Cloudflare.
- Аккаунт Cloudflare лучше на клиента (его почта, Михаил приглашён членом аккаунта). Тогда домен и сайт остаются у клиента, если Михаил пропадёт.
- Домен: Cloudflare Registrar продаёт по себестоимости, .com около $10.46 в год, продление по той же цене (сторонние трекеры, октябрь 2026, на странице Cloudflare цифры не видел). Цену .de не проверил, у немецких регистраторов обычно несколько евро в год (не проверено). Cloudflare Registrar продаёт не все зоны, .de проверить в панели.
- Генератор: Node 18+, без зависимостей. Фото: сжать до 1600 px по длинной стороне и до 400 КБ (squoosh.app в браузере), генератор предупреждает о файлах больше 500 КБ.
- Форма и цены: Google Таблица клиента + `Site.gs` как веб-приложение (бесплатно, лимит Apps Script 100 получателей писем в день на обычном аккаунте, 1 500 на Workspace, [квоты Apps Script](https://developers.google.com/apps-script/guides/services/quotas), видел через поиск 27.11.2026). Страница шлёт заявку обычным CORS-запросом и показывает «спасибо» только если скрипт ответил `ok`; иначе «не получилось, позвоните». Заявка пишется в таблицу и письмом: если одно из двух упало (лимит писем, блокировка таблицы), второе всё равно сохраняет заявку. Текст, который начинается с `=`, `+`, `-`, `@`, хранится как текст, а не как формула. Живьём с настоящим Apps Script ответ CORS не проверен: после деплоя отправить тестовую заявку с телефона.
- Профиль Google: веб business.google.com или приложение Google Карты. API для заполнения не нужен: на одного клиента руками быстрее, чем ждать доступ к API.

## 3. Один раз подготовить (Михаил)

1. Свой рабочий Google-аккаунт для профилей клиентов (тот же, что в reviews).
2. Аккаунт Cloudflare для тестов, `npx wrangler login`. Один пробный деплой: `node build.mjs examples/salon.json --out dist/studio-lila`, потом `npx wrangler pages deploy dist/studio-lila --project-name studio-lila-test`.
3. Мастер-таблица для формы и цен: новая Google Таблица, Расширения > Apps Script, вставить `apps-script/Site.gs`, манифест `appsscript.json`. На клиента: «Файл > Создать копию» в его аккаунте (на звонке, он сам входит).
4. Прочитать шаблоны Impressum и Datenschutz в `lib/render.mjs` (функции `impressumHtml`, `datenschutzHtml`). Это не юридическая консультация. Лучше один раз сверить с генератором eRecht24 или юристом и поправить шаблон; для клиники отдельно сверить с памяткой своей земельной палаты.
5. Короткое видео для клиентов: «как поменять часы и добавить отпуск в Google Картах» и «как поменять цену в таблице». Снять один раз на телефоне.
6. Прогнать `gbp/checklist.mjs` на примере и пройти чек-лист на тестовом профиле.

## 4. Шаги на заказ (реальное время)

Профиль Google (все ниши), 45-90 минут плюс ожидание Google:

1. Бриф и материалы в WhatsApp: часы, цены, адрес или районы, 5-15 фото, описание словами. 10 мин переписки.
2. Если профиля нет: видеозвонок 20-30 мин, владелец сам создаёт профиль в своём аккаунте, Google сам выбирает способ подтверждения (чаще видео: вывеска, помещение или машина, документ или инструмент, одним дублем; иногда СМС или звонок). Проверка видео до 5 рабочих дней. Если отклонили: переснять, исправив причину (часто название на вывеске не совпадает с профилем).
3. Владелец добавляет Михаила менеджером (без пароля). 5 мин.
4. `business.json` (тот же, что для сайта) и `node gbp/checklist.mjs client.json --out gbp.md`. Исправить всё из «FIX FIRST». 10 мин.
5. Заполнить по листу: категории, часы, особые часы, описание, услуги или меню с ценами, чат WhatsApp (если поле есть), сайт, районы, фото. 30-45 мин.
6. Через 1-3 дня проверить с чужого телефона без входа в аккаунт, отправить владельцу скриншот. 5 мин.

Сайт (shop, fitness, clinic, cleaning, other), 1,5-3 часа:

1. `business.json` по примеру: тексты на языках клиента (короткие, клиент присылает или ИИ переводит, клиент проверяет), цены, часы, фото, юр. данные для Impressum. 30-60 мин.
2. Фото сжать, положить рядом. `node build.mjs client.json --strict`. Без `--strict` предупреждения только печатаются, с ним сборка падает, пока Impressum не полный. 5 мин.
3. Открыть `dist/<id>/index.html` в браузере, проверить на телефоне (ширина 360 px). 10 мин.
4. Деплой: `npx wrangler pages deploy dist/<id> --project-name <id>`. Сайт сразу на `<id>.pages.dev`. 5 мин.
5. Домен: купить в аккаунте клиента, в Pages > Custom domains добавить, DNS сам. Если домен у другого регистратора: CNAME на `<id>.pages.dev`. 15-30 мин плюс до нескольких часов на DNS.
6. Ссылку на сайт в профиль Google. Показать владельцу, как попросить правку. 10 мин.

По нишам:

- shop (цены сам): копия мастер-таблицы на его аккаунте, лист «Prices» (Group, Item, Price, From, Show), `setupSite`, развернуть веб-приложение, URL в `prices_endpoint`, пересобрать. Показать в приложении Google Таблиц на телефоне. 30 мин. Цены в HTML остаются как запасной вариант, если таблица не ответит.
- fitness (запись): то же, URL в `booking.endpoint`, свойства `OWNER_EMAIL`, `CLIENT_ID`. Тестовая заявка с телефона, письмо пришло. 30 мин. Расписание: слоты в `booking.slots` (например «Sa 10:00»). Если расписание меняется каждую неделю, это уже сервис записи (Cal.com и т.п., услуга bot), не этот набор.
- clinic: Impressum с палатой, профессией и страной выдачи, правилами профессии и KZV или KV (поля `legal.*`). Никаких форм для пациентов. Фото без пациентов и без «до и после». 30 мин сверх обычного.
- trades, cleaning: `hide_address: true`, `service_area`. Адрес для Impressum в `legal.address` (на сайте он только в Impressum, это обязательно).
- salon, cafe: обычно только профиль. Если сайт нужен, тот же генератор.

## 7. Ограничения, право, правила площадок

- Подтверждение профиля решает Google: способ выбирает он, видео бывает отклонено, бывает «больше нет способов подтверждения». Обещать «будешь на карте» можно только после успешного подтверждения. Код из СМС Google сейчас приходит не всегда, чаще видео.
- Создаёт и владеет профилем всегда клиент, со своего аккаунта. Михаил только менеджер. Иначе при расставании профиль застрянет у Михаила.
- Название профиля: только настоящее название с вывески и счетов. «Электрик Берлин дёшево 24/7» Google считает спамом, профиль могут заблокировать. `checklist.mjs` это проверяет.
- Описание: до 750 знаков, без ссылок, телефонов и акций.
- Кнопка WhatsApp в профиле (поле «Чат»): по справке Google доступна в отдельных странах и регионах, Германию в списке подтвердить не удалось (не проверено). Если поля нет: ссылка wa.me на сайте, а на сайт ссылка из профиля.
- Место в выдаче Google не обещаем: Google учитывает расстояние, полноту профиля, отзывы. «Больше отзывов, выше» верно только как тенденция, поэтому на сайте этого больше нет.
- Impressum: обязателен по §5 DDG (раньше TMG) для любого сайта фирмы. Для ремесла и врачей добавляются палата, профессия, правила профессии. Шаблоны в генераторе не юридическая консультация.
- Datenschutz: сайт без cookies и без внешних ресурсов, это сознательно (Google Fonts с сервера Google в Германии приводил к искам, LG München 2022). Карта только ссылкой, не встроенным iframe. Хостинг Cloudflare: обработка IP в логах, у Cloudflare есть DPA для клиентов (что DPA входит в бесплатный тариф автоматически, не проверено, проверить в панели Cloudflare). Форма: данные идут в Google-аккаунт клиента. С обычным бесплатным Gmail договора обработки данных с Google нет, для небольших заявок это частая практика, но не идеальная; для клиник и при чувствительных данных только Google Workspace с принятым DPA.
- Форма: галочка согласия, ловушка для ботов, лимит 30 заявок в час, удаление через 90 дней (`cleanupBookings`). Не спрашивать ничего лишнего (например здоровье в фитнесе).
- Клиника (HWG и профессиональные правила): без обещаний результата, без «до и после», без отзывов пациентов на сайте, цены частных услуг только честно «от» и с пометкой «по GOZ/GOÄ». Никаких данных пациентов: на сайте нет формы со свободным текстом.
- Цены с НДС: генератор пишет «Preise inkl. MwSt.» (PAngV), для врачей выключено (`prices_vat_note: false`). Kleinunternehmer по §19 UStG: поправить фразу в `lib/i18n.mjs` (не проверено, как лучше сформулировать, уточнить у налогового консультанта).
- «Сегодняшнее меню», «актуальные цены» поддерживает владелец сам. Михаил за €29 делает одну настройку.
