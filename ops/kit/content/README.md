# content: фото, видео и тексты из снимков владельца

Цена на сайте: €1 за фото (без «от»: карточка показывает ровно «€1 за фото», `v-fast/fx/contact.js`). Видео и ролики на сайте не оценены, правило ниже в разделе 8. Сторонние расходы: в нише salon сайт пишет про сторонние расходы (`fee: true`), по факту они около нуля (раздел 6).
Проверено 27.11.2026. Что не удалось проверить первоисточником, помечено «не проверено».

Состав набора:

- `bin/content.mjs` - пакетная обработка одного клиента на ноутбуке: фото, ролики, подписи, сообщение владельцу. Уже сделанные файлы пропускает (по содержимому).
- `pipeline/photo.mjs` - фото через sharp: поворот по EXIF, свет, обрезка 4:5 (лента), 9:16 (статус, сторис, без обрезки: фото целиком на размытой копии), квадрат по желанию, удаление всех метаданных (GPS, модель телефона). HEIC через `heif-convert`, если установлен.
- `pipeline/background.mjs` - чистый фон для товара (shop): Photoroom API или бесплатный локальный `rembg`, по умолчанию выключено.
- `pipeline/video.mjs`, `pipeline/srt.mjs` - ролики через ffmpeg: вертикаль 1080x1920, тот же свет, что у фото, кусок до 15-20 секунд (середина видео или отрезок из подписи владельца `0:12-0:30`), субтитры из `.srt` (whisper.cpp или руками), слайд-шоу из фото.
- `app/` - приложение для телефона (salon): делает фото светлее прямо на телефоне, ролик из фото, текст. `app/enhance.js` это одна и та же формула света для телефона и ноутбука.
- `worker/` - Cloudflare Worker: раздаёт приложение и пишет подпись (ключ Anthropic только там). Фото не хранит.
- `drive/Watch.gs` - Apps Script в аккаунте Михаила: новые файлы в папке «Входящие» клиента, сообщение в Telegram со сроком сдачи.
- `core/captions.mjs` - промпт подписи к одному фото, ролику или набору. Проверки и модель общие с набором `social` (`../social/src`).
- `templates/messages.json` - сообщения владельцу на ru, uk, de, en: сдача работы, как снимать, формат iPhone, как пользоваться Google Диском, установка и работа приложения.
- `clients/*.example.json` - вымышленные клиенты для всех 5 ниш.
- `test/` - офлайн-тесты: `cd ops/kit/content && npm install && npm test` (32 теста, все проходят; ffmpeg реально запускается на сгенерированном видео, Anthropic и Photoroom подменены).

## 2. Стек

- **Node 22 + sharp 0.35** (libvips, бесплатно) для фото. Формула света одна для ноутбука и телефона (`app/enhance.js`): чёрная точка двигается мало, белая растягивается не больше чем в 1,4-1,6 раза, средние тона поднимаются гаммой до цели ниши, лёгкая правка цветового оттенка (в пределах 10 %), лёгкая насыщенность. Тест проверяет на 1 000 случайных гистограмм: результат никогда не темнее исходника и кривая монотонна. Генеративного ничего нет.
- **ffmpeg** (бесплатно, `apt install ffmpeg` / `brew install ffmpeg`) для роликов: H.264, AAC, yuv420p, faststart, 1080x1920, 30 к/с. Это формат, который принимают Instagram и WhatsApp.
- **whisper.cpp** (бесплатно, офлайн, по желанию) для субтитров: `whisper-cli -m ggml-small.bin -f audio.wav -osrt`. Путь в `content.whisper` клиента. Нет whisper: субтитры из `.srt`, написанного руками, или без субтитров.
- **Фон товара**: `"provider": "none"` (по умолчанию), `"photoroom"` (ключ `PHOTOROOM_API_KEY` в окружении, $0.02 за фото по [Photoroom](https://docs.photoroom.com/getting-started/pricing), тарифы от $20 в месяц за 1 000 фото по [странице цен](https://www.photoroom.com/api/pricing); точную цену на живой странице не открывал, не проверено) или `"command"` с `rembg` (бесплатно, локально). Для €1 за фото Photoroom окупается только при 1 000 фото в месяц по всем клиентам, поэтому начинать с `rembg`. remove.bg не брать: по [блогу Photoroom](https://www.photoroom.com/blog/remove-bg-api-cost-leonardo-ai-vs-photoroom) его самообслуживаемый API закрывается 01.12.2026 (сообщение конкурента, не проверено).
- **Подписи**: Anthropic Messages API, `claude-haiku-5-5`, видит фото. Haiku 5.5 думает по умолчанию, эти токены входят в `max_tokens`, поэтому стоит 2000 (было 600, ответ мог обрезаться). Цена $0.10 / $0.50 за 1 млн токенов действует для запросов до 100 000 токенов (таблица моделей Anthropic, кэш 03.11.2026; живую страницу цен не открывал). Те же правила честности и та же проверка цен и времени, что в `social`. Провайдер и модель меняются переменными `LLM_PROVIDER`, `LLM_MODEL`.
- **Приложение salon**: статичные файлы `app/` раздаёт Cloudflare Worker `worker/` (бесплатный план: 100 000 запросов в день, 1 000 записей KV в день, запросы к статике бесплатны, [лимиты KV](https://developers.cloudflare.com/kv/platform/limits), [цены Workers](https://developers.cloudflare.com/workers/about/pricing)). Один Worker на всех клиентов-приложений в аккаунте Михаила. Вход по личной ссылке с токеном, Worker хранит только sha256 токенов (секрет `CLIENTS`). Лимит подписей в день на клиента (по умолчанию 40).
- **Google Диск**: папка в аккаунте клиента, доступ Михаилу на редактирование. На ноутбуке Google Drive для компьютера, папка синхронизируется, `--in` это «Входящие», `--out` это «Готово».
- **Telegram-бот** Михаила для уведомлений (`drive/Watch.gs`).

## 3. Подготовка один раз (Михаил)

1. `cd ops/kit/content && npm install && npm test`. Установить ffmpeg. По желанию `heif-convert` (`apt install libheif-examples`, на Mac есть `sips`) и whisper.cpp с моделью `ggml-small.bin` (около 500 МБ, хорошо понимает ru, uk, de, en).
2. Ключ Anthropic как в `social` (тот же или отдельный «content»), лимит $5 в месяц.
3. Пробный прогон: `npm run demo`, открыть `/tmp/content-demo`.
4. Приложение (один раз на всех клиентов, около 1 часа):
   - `npx wrangler login`; `cd worker`; `npx wrangler kv namespace create USAGE`, id в `wrangler.toml`.
   - `npx wrangler secret put ANTHROPIC_API_KEY`.
   - Пустой список клиентов: `echo '[]' | npx wrangler secret put CLIENTS`; `npx wrangler deploy`. Адрес вида `photo-app.<аккаунт>.workers.dev`. Ключ `run_worker_first` в `[assets]` сверить с актуальной документацией wrangler при первом деплое (не проверено на живом аккаунте).
   - Проверить на своих iPhone и Android: установка на экран, выбор фото, сохранение, ролик (mp4 на iPhone; на старых Android может выйти webm, см. раздел 7).
   - Главная проверка на iPhone: приложение на экране «Домой» открывается уже с именем салона, а не с «Ссылка не работает». У приложения на экране iPhone своё хранилище, отдельно от Safari, поэтому токен, сохранённый в Safari, туда не попадает. Исправлено скептиком: токен остаётся в адресе (`#t=`), в manifest нет `start_url`, а если токен всё же потерялся, приложение просит вставить код из сообщения `app_install` (там теперь есть `{code}`). Раньше адрес очищался и в manifest стоял `start_url: "./"`: на iPhone приложение с экрана «Домой» почти наверняка открывалось бы без входа. На живом iPhone не проверено.
   - Лимиты бесплатного Cloudflare: 10 мс процессора на запрос и 5 КБ на один секрет ([лимиты Workers](https://developers.cloudflare.com/workers/platform/limits/), по поиску 27.11.2026, страница не открылась). Ожидание ответа Anthropic в 10 мс не входит; разбор JSON с 3 фото по 100 КБ укладывается, но если в логах будет ошибка 1102, нужен платный план Workers ($5 в месяц, платит Михаил). Секрет `CLIENTS` вмещает около 10 клиентов (одна запись около 460 байт); `bin/app-token.mjs clients` теперь отказывается выдать больше 5 000 байт.
5. Telegram-бот через @BotFather, свой chat id. Apps Script: script.google.com, новый проект, вставить `drive/Watch.gs` и `drive/appsscript.json`, свойства `TG_TOKEN`, `TG_CHAT_ID`, `CLIENTS_JSON` = `[]`, запустить `setup()`.
6. Памятка «как снимать» (`shooting_tips`) и шаблон AVV (общий с `social`).

## 4. Шаги на заказ (реальное время)

Общее (пакет 10-20 файлов): `node bin/content.mjs run --client clients/<id>.json --in <входящие> --out <готово> [--link <ссылка>]` работает 10-60 секунд. Потом Михаил смотрит каждое фото и подпись, правит пометки CHECK в `captions.txt`, отправляет `message.txt`. Проверка 1 минута на фото, 2-3 минуты на ролик.

- **cafe** (WhatsApp, через 2 дня): сохранить файлы из WhatsApp Web в папку, подписи владельца в `notes.txt` (5 минут), прогон, проверка 15-20 минут на 15 фото, отправка «Документом» 5 минут. Итого 30 минут на €15.
- **shop** (ссылка): то же плюс фон. Папка для ссылки может быть в Google Диске Михаила, только если на фото нет людей (товар без лиц это не персональные данные). Если в кадре люди, папка в аккаунте клиента или файлы «Документом» в WhatsApp. С `rembg` около 3 секунд на фото на ноутбуке. Иногда край товара вырезан плохо: такое фото отдаю без замены фона. Ссылка на папку Google Диска с доступом «по ссылке, просмотр», через 30 дней закрыть. 30-40 минут на 15 фото.
- **fitness** (Google Диск): первый раз 20 минут на звонке: создать в его Google Диске папку «<Имя> контент» с «Входящие» и «Готово», дать мне доступ, добавить в `CLIENTS_JSON` Watch.gs: `{"id":"fitness-kraft","inbox":"<id папки Входящие>","days":2}`, на ноутбуке «Добавить ярлык в Мой диск», чтобы синхронизировалась. Дальше по сообщению в Telegram: прогон (whisper добавляет около 1 минуты на минуту видео), проверка, `message.txt` в WhatsApp. 30-45 минут на 10 файлов с 3 роликами.
- **other**: как fitness или как cafe, по тому, как он шлёт.
- **salon (приложение)**, первый раз 45-60 минут:
  1. Она шлёт 10 фото работ. Прогоняю через `bin/content.mjs` с `"niche": "salon"`, смотрю, не перебор ли света на её лампах (часто тёплые). Если да, в `app` пока одна формула на нишу, правлю `PRESETS.salon` в `app/enhance.js` или делаю отдельную нишу-пресет. 15 минут.
  2. `node bin/app-token.mjs new`: токен и хеш. Хеш в `clients/salon-<имя>.json` (`app.token_sha256`), там же стиль, хештеги, цены.
  3. `node bin/app-token.mjs clients clients | npx wrangler secret put CLIENTS` (в секрет идут только нужные поля, без телефонов).
  4. Ссылка `https://photo-app.<аккаунт>.workers.dev/#t=<токен>` в WhatsApp с текстом `app_install`, затем `app_howto`. На видеозвонке поставить ярлык и сделать первый пост вместе. 20 минут.
  5. Если ссылка утекла: новый токен, шаг 2-4 заново, старый сразу перестаёт работать.

## 7. Ограничения, право, правила платформ

- **Честные фото.** Только свет, цвет, кадр, фон вокруг товара. Нельзя: дорисовывать еду, менять порцию, ретушировать кожу или ногти, «улучшать» результат тренировки, добавлять предметы. Фото, которое показывает блюдо или товар лучше, чем он есть, это вводящая в заблуждение реклама (UWG §5). Если фото плохое (темно, смазано, меньше 720 пикселей), прошу переснять, а не «спасаю» ИИ. Пометка ИИ от Meta нужна для сгенерированного контента; у нас генерации в картинках нет.
- **Подписи** пишет модель, проверяет Михаил. Цены и время в тексте только из слов владельца (`guard.mjs`).
- **Персональные данные (GDPR).** На фото клиенты, гости, участники зала: Михаил обработчик, нужен AVV (ст. 28). Обработчики Михаила: Anthropic (фото для подписи; данные API по умолчанию не используются для обучения по Commercial Terms, сверить перед первым заказом, не проверено в этой сессии), Cloudflare (Worker, фото не хранит и не логирует), Google (Диск клиента, это его договор с Google). Папки в своём бесплатном Google аккаунте для чужих клиентов не держать: у бесплатного Google нет договора обработки данных. Поэтому папка создаётся в аккаунте клиента. Исходники на ноутбуке удалять через 30 дней после сдачи. Метаданные (GPS) удаляются из всех готовых фото.
- **Лица и согласие.** Публиковать лицо или узнаваемого человека только с его согласия (GDPR ст. 6, §22 KUG). Шаблон согласия на 4 языках. Результаты тренировок с цифрами веса это данные о здоровье (ст. 9): только явное письменное согласие участника.
- **Музыка.** В ролики музыку не добавляю (права). Звук видео: оставляю голос тренера (fitness) или убираю (cafe, shop). Музыку из библиотеки Instagram владелец добавляет сам при публикации.
- **Instagram.** Лента лучше всего 4:5 (1080x1350), сторис и статус 9:16 (1080x1920). Видео H.264 mp4. Для отложенных постов нужен профессиональный аккаунт (см. `social`).
- **Приложение (PWA), честные пределы:**
  - Положить файл прямо в галерею веб-приложение не может. Работает через меню «Поделиться»: «Сохранить изображения» (iPhone) или «Сохранить» (Android). Это одно лишнее нажатие. На старых браузерах без такого меню файлы скачиваются в «Загрузки».
  - Ролик в приложении: слайд-шоу из фото или первые 15 секунд одного видео, без звука. Формат mp4 там, где браузер умеет записывать mp4 (Safari на iPhone, новые Chrome), иначе webm. Webm Instagram может не принять: тогда ролик делаю я на ноутбуке. Свет в видео в приложении простой (фильтр браузера), на ноутбуке точный.
  - Без интернета фото обрабатываются, текст нет.
  - HEIC с iPhone Safari обычно сам превращает в JPEG при выборе фото (по опыту, не проверено на всех версиях iOS).
  - Тексты на телефоне не сохраняются на сервере, фото на сервер уходят только в уменьшенном виде для подписи и не хранятся.
- **Холодные рассылки** (UWG §7): этот набор никому не пишет, кроме владельца. WhatsApp-рассылки и шаблоны Meta не используются.

Цена роликов: на сайте «€1 за фото», ролик отдельно не назван. Правило для заказа (сказать клиенту до начала, в сообщении о цене): один исходный файл = €1; ролик до 15 секунд без субтитров из одного видео = €1 (обрезка и свет автоматом, 2-3 минуты проверки); ролик с субтитрами = €3 (whisper.cpp плюс проверка каждого слова, 5-10 минут). Видеореклама на 15 секунд остаётся отдельной услугой. Без этого правила клиент fitness, который шлёт в основном видео, платит €1 за час работы.

Приложение salon: «€1 за фото» превращается в €10 за настройку (10 фото), дальше она пользуется сама в пределах 40 подписей в день, подписи оплачивает Михаил (меньше $1 в месяц). Это обязательство без срока: в сообщении о цене назвать срок, например «приложение работает 12 месяцев, потом продление €10». Это решение владельца сайта, в коде лимит есть, срока нет.
